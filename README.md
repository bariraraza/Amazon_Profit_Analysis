# Amazon Profit Prediction — Linear Regression

An end-to-end Machine Learning project demonstrating data preprocessing, exploratory data analysis (EDA), and profit prediction using Linear Regression.

---

## 📌 Project Overview
This repository contains a predictive modeling workflow built to analyze key business drivers affecting profit margins:
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA) using Matplotlib & Seaborn
- Model development with Linear Regression
- Evaluation of predictive performance

---

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn, Scikit-Learn
- **Environment:** Google Colab / Jupyter Notebook

---

## 📂 Repository Contents
- `Amzn_prft_linear_regression.ipynb` — Primary analysis notebook with step-by-step model execution and visualizations.
- `profit_mdl_train_cleaned (1).csv` — Preprocessed dataset used for model training.
- `README.md` — Project summary and instructions.
